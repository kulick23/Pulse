# Changelog

## 2026-10-28 — Git history established

Pulse was developed locally before the project was connected to Git. This entry records the completed work honestly; the commits created with this import are grouped by product area rather than backdated.

### Product

- Reworked the original site into Pulse, a European fintech super app concept.
- Added the public website, personal banking, business banking, investing, mobile, insurance, travel, and shop experiences.
- Added Russian and English localization with persistent language selection.

### Banking foundation

- Added multi-currency accounts, cards, transfers, payments, cashback, and operation history.
- Added a local typed ledger shared by paid ecosystem services.
- Added cancellation, repeat-payment, insufficient-balance, loading, empty, and error scenarios.

### Engineering

- Split large pages into domain modules.
- Added versioned browser storage with migrations.
- Added accessibility behavior for dialogs, focus restoration, keyboard navigation, and responsive reflow.
- Added critical ledger tests and smoke coverage for every application route.
- Completed desktop and mobile route checks at 1440, 390, and 320 CSS pixels.

### Brand

- Added an original Pulse favicon and PWA icon set.
